# Into The Haunted Land Press Kit

Static press kit for GitHub Pages.

Open `index.html` locally or publish this repository with GitHub Pages from the repository root.

Editable page text lives in:

- `content/developer.txt`
- `content/pitch.txt`
- `content/description.txt`
- `content/main-text.txt`

Images in `assets/logoandkey` are loaded automatically into the "Logos and key art" horizontal scroll section on GitHub Pages. Card labels are generated from the image file names.
